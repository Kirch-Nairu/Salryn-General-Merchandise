# Salryn support & FAQ

[Product overview](README.md) · [Installation](INSTALLATION.md) · [Releases](https://github.com/Kirch-Nairu/Salryn-General-Merchandise/releases)

## Product support

Contact **salryn.info@gmail.com** for onboarding, activation, installation assistance, hardware compatibility and product issues.

For an issue report, include the installed version, Windows edition, affected workspace, what you expected to happen, what happened instead, and steps to reproduce with fictional data where possible. Include a screenshot or relevant error message only after removing customer details and sensitive information. Never post license files, passwords, transaction databases, payment details or customer records to this public repository.

## Frequently asked questions

**Is this a source-code repository?**

No. This is the official public product-information and installer distribution repository for Salryn General Merchandise. Source-code archives automatically generated by GitHub contain only this public documentation.

**Can I use Salryn without internet?**

Routine local Host operations are designed to work without continuous internet. Initial WebView2 setup, installer downloads, support and certain onboarding activities may require connectivity.

**Do I need to install a database or developer tools?**

No separately managed database server or developer toolchain is required for the supported Windows Host installation.

**Can multiple employees use the application?**

Individual operator accounts and Admin, Manager and Cashier permissions are provided. Do not share credentials. Multi-workstation LAN terminals are a future feature, not part of the current pilot candidate.

**Do all licenses include Utang?**

No. Accounts Receivable / Utang is an optional licensed Host feature. Ask Kirjane about the applicable entitlement.

**Does reprinting a receipt make another sale?**

No. Receipt reprinting uses the preserved transaction record. Any correction or void should follow the authorized workflow rather than altering saved records.

**Do quotes or purchase requests automatically change inventory?**

A quote or request is a planning document, not a completed sale or received shipment. Inventory changes follow the applicable checkout, stock movement or goods-receiving workflow.

**Is Salryn a full accounting or BIR-certified system?**

No such claim is made. It provides retail operating records and business-management tools. Consult the publisher and your qualified adviser about regulatory and accounting requirements.

**Will an update erase my data?**

The installer is designed to preserve local application data, but Beta RC1 upgrade preservation and rollback have not passed native acceptance. Do not upgrade a live client installation with this beta. Before any future authorized update, verify a separate backup and confirm license recovery and rollback with support.

**Is Beta RC1 available, and can I use it in my store?**

[Beta RC1 is available](https://github.com/Kirch-Nairu/Salryn-General-Merchandise/releases/tag/v0.1.0-rc1) as an unsigned (`NotSigned`) pilot prerelease. Use a disposable Windows test environment with fictional data. It is not production-approved; do not upgrade a live client installation. Shared installer/data identity makes side-by-side use unsuitable. Read the release notes for incomplete native/security acceptance, pending independent review, unverified packed payload, and the failed mocked browser suite.

## Security and updates

Use only the official release assets, verify the published checksum and signature state, follow your organization's security requirements, and contact support about unexplained warnings. Do not post details of suspected vulnerabilities or sensitive technical evidence publicly; contact support privately.

Salryn is proprietary software distributed under applicable customer licensing and service agreements. Public download access does not by itself grant an unrestricted license.
